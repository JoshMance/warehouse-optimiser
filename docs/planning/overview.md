# Overview

## Purpose/Scope

    This software uses a cellular-automata approach to model the movements of employees in a small warehouse
    as they collect lists of products. This simulation will allow us to investigate the efficiency of different list-ordering herustics ('closest product first', etc.), taking into account emergent effects such as traffic congestion.

    The end-product will be a simple gui that can be used to set the parameters and run a simulation.

## Goals and Objectives

    The primary goal for this software is performance.
